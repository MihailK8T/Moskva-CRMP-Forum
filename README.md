# Москва CRMP — форум

Полноценный форум для игровых RP-проектов (SAMP/CR-MP) на **PHP + MySQL**, с админ-панелью уровня XenForo и максимальной интеграцией с игровым сервером.

## Возможности

**Публичная часть**
- Разделы, темы, посты с пагинацией, прикреплением (📌) и блокировкой (🔒)
- BBCode: `[b]`, `[i]`, `[u]`, `[s]` `[quote]`, `[code]`, `[img]`, `[url]`, `[color]`, `[size]`, `[spoiler]`, списки
- Реакции 👍, цитирование, жалобы на посты, редактирование
- Регистрация / вход, поиск, профили с подписью и «о себе»
- Уведомления: ответы в подписках, упоминания `@ник`, новые ЛС
- Личные сообщения (конверсации)

**Админ-панель** (`/admin/`, доступ по ролям)
- Дашборд со статистикой
- Пользователи: просмотр, последние посты, выдача уровней админки
- Баны / разбан — работают с общей таблицей `bans` (бан на форуме = бан в игре)
- Разделы: создание, редактирование, порядок, удаление
- Темы: закрепить / закрыть / удалить
- Жалобы: обработка (решено / отклонить)
- Настройки: название, описание, открытие/закрытие, лимиты

**Интеграция с игрой**
- Единая база `samp_rp`, вход через таблицу `accounts`
- Роль на форуме берётся из `admin_level` в игре (1–2 → модератор, 3+ → администратор)
- Пароли понимают и bcrypt (форум), и SHA-256 (гейм-мод)

## Установка

1. Клонируйте репозиторий, скопируйте `inc/config.example.php` в `inc/config.php` и заполните доступы к БД.
2. Импортируйте схему:
   ```
   mysql -u <user> -p samp_rp < sql/forum_schema.sql
   ```
3. Положите папку в корень веб-сервера (Apache/Nginx + PHP 8) или запустите встроенный сервер:
   ```
   php -S localhost:8080
   ```
4. Откройте в браузере `http://localhost:8080`. Админ-панель — `http://localhost:8080/admin/`.

## Требования

- PHP 8.0+
- MySQL 5.7+ / MariaDB 10.3+
- Расширение PDO_MySQL или mysqli
- `.gitignore` скрывает `inc/config.php` — секреты не попадают в репозиторий
